INSTALLATION

  1. Install Millennium

    Use the official installer and open desktop Steam.

  2. Download and configure

    Extract the ZIP. Follow its README to set shortcut IDs and game adapter paths.

  3. Build and restart Steam
    bun install
bun run build

    Enable Custom Achievements in Millennium.

  4. Start the tracker
    python tracker/daemon.py

    Keep it running while you play. Use Test notification to check delivery.

  5. Connect your Steam account

    In the plugin settings, select Connect Steam cloud and approve this device. Repeat on each device to sync progress.

HOW IT WORKS

The tracker reads supported game progress. The plugin adds achievement panels and unlock notifications to Steam.

These are custom achievements, separate from official Steam profile achievements.
