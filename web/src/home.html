Setup & compatibility
  1. Close Steam and run the installer.
  2. Restart Steam and enable Custom Achievements in Millennium.
  3. Open Custom Steam Achievements Setup to select game saves. Visit the game's library page once.

Connect Steam cloud in plugin settings to sync progress. Live Ocarina and Pokopia tracking requires Linux and a configured game runtime. Windows gameplay support is experimental.

Desktop Steam only; no Flatpak, Snap or Decky. Custom achievements do not count toward official Steam profile totals.
